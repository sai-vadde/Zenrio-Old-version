# Zenrio Old Version

This repository contains an older version of the Zenrio website.

The current live website is available at [https://www.zenrio-agency.com](https://www.zenrio-agency.com).

If you are viewing this codebase, please check the latest version of the website there.

## Local Development

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
